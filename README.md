# 🤖 Employee Layoff Prediction & Analytics Dashboard

An interactive **Machine Learning + Data Analytics** project built using **Streamlit** that predicts employee layoff risk and provides deep insights through visual dashboards.

---

## 📌 Project Overview

This project analyzes employee data and predicts the probability of layoffs using multiple machine learning models. It also provides interactive visualizations to understand trends across industries, salaries, demographics, and performance.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup system)
- 📊 Interactive Dashboard with Filters
- 📈 Layoff Trend Analysis (Year, Industry, Company)
- 👥 Demographic Insights (Age, Gender, Experience)
- 💰 Salary Analysis
- 🤖 Machine Learning Models:
  - Random Forest
  - Gradient Boosting
  - Logistic Regression
  - XGBoost (optional)
- 📉 Performance Metrics:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - ROC-AUC
- 📊 Confusion Matrix & ROC Curve
- 👤 Individual Employee Risk Prediction
- 📌 Feature Importance Visualization

---

## 🧠 Machine Learning Workflow

1. Data Generation & Preprocessing  
2. Feature Engineering  
3. Train-Test Split  
4. Model Training (Multiple Models)  
5. Cross Validation  
6. Evaluation Metrics  
7. Prediction on New Data
